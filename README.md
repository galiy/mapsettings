# mapsettings

Отдельная кроссплатформенная программа для **чтения, инспекции и редактирования
настроек инвертора МАП** (SVEN POWER MANAGER II; модели **Титанатор** и
**Доминатор**) через веб-интерфейс. Чтение и запись — по **Modbus TCP** к
`mapgateway` (порт 502 на ПАК «Малина»).

Приложение самодостаточно: интерфейс и каталог ячеек встроены в один бинарник
(`go:embed`), внешних зависимостей нет — только стандартная библиотека Go.

> ⚠️ **Внимание.** Программа пишет реальные значения в EEPROM/RAM контроллера и
> выполняет управляющие команды. Это может быть необратимо и опасно для
> оборудования. Перед использованием прочитайте
> [DISCLAIMER.md](DISCLAIMER.md).

## Возможности

- **Кнопки «Перечитать» и «Записать».** «Перечитать» снимает полный снимок
  параметров; «Записать» отправляет на МАП **только изменённые** пользователем
  параметры.
- **Все параметры с русскими именами и по логическим блокам.**
- **Служебное обрамление записи** (как делает `mapd`):
  `03 (ComMAP_EEPromWR) → запись → 07 (ComMAP_Call_load_EEProm)` + чтение-обратно.
- **Тип МАП определяется автоматически** при первом чтении по ячейке
  `_DevOpt` (0x007): Титанатор или Доминатор (от типа зависит набор
  параметров). Определённый тип показан в селекторе «Модель»; его можно
  переопределить вручную. В настройках тип не хранится — сохраняются только
  IP и порт.
- **Экраны по разделам.** На главной — только настройки программы (модель, IP,
  порт, «Перечитать»), форма **текущего времени** МАП и кнопки разделов. Каждый
  логический блок каталога открывается на своём экране (одноимённые rw- и
  ro-ячейки — на одной странице); команды `ComMAP_ON/OFF/ChargeON/ChargeOFF/
  StatReset/DischOff/load/Reset` — на отдельном экране «Управляющие
  воздействия». В шапке раздела — «Перечитать», «Записать», «На главную» и
  переходы в остальные разделы.
- **Редакторы по типу параметра**: число, радиогруппа (перечислимые) или
  чекбоксы (битовые маски).
- **Кнопка «?»** у каждого параметра и органа управления — подсказка из
  документации (описание целиком, единица/формула, расшифровка значений и
  битов). Описание собирается из всей области документа, относящейся к
  параметру.
- **Многобайтные значения** (24- и 32-битные счётчики) объединяются в один
  параметр; **битовые регистры** выводятся несколькими подписанными контролами
  (`fields`), а перечисления/биты мониторинговых (ro) параметров — неактивными
  radio/чекбоксами.
- Единицы измерения и допустимые диапазоны для ячеек.

## Сборка и запуск

Требуется Go 1.26+.

```sh
git clone https://github.com/galiy/mapsettings
cd mapsettings
go build -o mapsettings .        # или: make build
./mapsettings
# открыть http://127.0.0.1:8099/
```

Флаги:

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `-listen` | из `mapsettings.json` | адрес HTTP-сервера (переопределяет конфиг) |
| `-user` / `-pass` | пусто | HTTP Basic для `/api/*` (пусто — без авторизации) |
| `-version` | | показать версию и выйти |

Кросс-сборки: `make cross VERSION=0.1.0` (linux/windows/darwin, без внешних
зависимостей).

Отладочная сборка: `make build-debug` (`-X main.debug=true`) включает нумерацию
всех элементов интерфейса (№1, №2, …) — номер всплывает сразу при наведении.
Номера **детерминированные и не сдвигаются**: порядок id зашит в
`dbgindex_order.go` (append-only, `make dbg-order` дописывает только новые id в
конец). Список id → № отдаётся клиенту через `GET /api/dbgindex` (в обычной
сборке выключено). Индекс с типами элементов — `.kilo/dbg-index.txt`
(в `.gitignore`), обновляется командой `make dbg-index`. После добавления
элементов интерфейса: `make dbg-order && make dbg-index`.

### Локальный конфиг

Настройки связи хранятся в **`mapsettings.json`** рядом с модулем: два блока —
`read` (чтение) и `write` (запись). Любое изменение в UI сохраняется сюда и
очищает загруженные параметры. Тип МАП не хранится — определяется при чтении.
Если файла нет, он создаётся при первом запуске. Файл и бинарник **не коммитятся**. Рядом ведётся лог **`mapsettings.log`**
(время, чтения/записи/команды, результаты и ошибки); он тоже в `.gitignore`.

Все настройки задаются через веб-UI; `mapsettings.json` создаётся автоматически
при первом запуске/сохранении. Отдельного файла-шаблона в проекте нет.
Для COM в UI выбираются порт и скорость; для чтения/записи по Малине — host,
логин и пароль.

## API

| Метод и путь | Назначение |
|---|---|
| `GET /api/config` | блоки настроек `read`/`write` |
| `POST /api/config` | сохранить настройки в `mapsettings.json` |
| `GET /api/ports` | список COM-портов (Linux) |
| `GET /api/settings?mode=` | снимок: `settings` (rw) + `monitor` (ro) + `actions`; без `mode` тип определяется по `_DevOpt` |
| `GET /api/param?...&key=` | чтение одного параметра (для кнопки «Читать») |
| `GET /api/dbgindex?mode=` | индекс отладочных номеров (только debug-сборка) |
| `POST /api/apply` | `{mode,changes:{key:value},allowDanger}` — запись одного параметра выбранным способом записи |
| `POST /api/action` | `{mode,key}` — управляющее воздействие |
| `GET /api/time` / `POST /api/time` | чтение/запись времени МАП |

## Каталог ячеек

Источник — документ производителя `protocol_MAP_cells_2026_07_15.doc`
(единственная актуальная версия; веб-API ПАК «Малина» как эталон **не**
используется — оно старое). Документ в этот репозиторий не выгружается; здесь
лежит производный `catalog.json` (227 параметров), встроенный в бинарник.

Генератор `catalog_gen.py` (требуется `libreoffice`):

```sh
python3 catalog_gen.py --doc ../sunReceiver/docs/map/map/protocol_MAP_cells_2026_07_15.doc
# или задать путь через переменную окружения MAPSETTINGS_DOC
```

Скрипт детерминирован и проходит самопроверки (русские имена, корректные
`width`/`order` парных байт, уникальные ключи, единицы, диапазоны).

## Безопасность

- Записываются только параметры с `access=rw`; служебная область `0x000..0x004`
  защищена от записи.
- 48 опасных параметров (мощность, напряжения/токи АКБ, калибровки, аппаратная
  конфигурация) помечены `danger` и по умолчанию не редактируются; слева от
  имени стоит красная метка «▲ Опасно!», редактирование включается кнопкой 🔒
  в строке на время сессии. В общую запись заблокированные не
  попадают; одиночное сохранение опасного параметра требует подтверждения.
  Сервер также отклоняет запись `danger`-ячеек без явного флага `allowDanger`.
- В каждой строке — кнопки «Читать» (перечитать только этот параметр) и
  «Сохр.» (сохранить только этот параметр, если он изменён); для
  нередактируемых и заблокированных «Сохр.» недоступна.
- Перед записью — служебное разрешение (команда `03`), после — фиксация (`07`) и
  чтение-обратно (верификация); расхождение попадает в результат.
- Опасные действия (включение/выключение, сброс, запрет разряда) требуют
  подтверждения в UI.

## Структура

| Файл | Назначение |
|---|---|
| `main.go` | флаги, разбор адреса, запуск HTTP-сервера |
| `config.go` | локальный конфиг `mapsettings.json` |
| `server.go` | HTTP API и отдача UI (embed `web/`) |
| `catalog.go` | каталог, чтение снимка, дельта-запись, действия, время |
| `modbus_client.go` / `modbus_write.go` | Modbus TCP: чтение 0x03, запись 0x06/0x10, команды |
| `catalog.json` / `catalog_gen.py` | каталог ячеек и его генератор |
| `web/` | `index.html`, `app.css`, `app.js` |
| `catalog_test.go` | тесты каталога и разбора значений |
