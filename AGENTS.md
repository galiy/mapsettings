# Правила проекта mapsettings

## Логи

- Программа ведёт лог `mapsettings.log` рядом с бинарником (в `.gitignore`):
  время, все значимые действия **со всеми параметрами**, результаты и ошибки.
  Пароли в лог не пишутся (маскируются `***`).
- **После каждой итерации исправления ошибок удалять лог**
  (`rm -f mapsettings.log mapsettings.log.*`) **и перезапускать фоновый сервер**,
  иначе процесс продолжает писать в удалённый inode и файл не появляется.
  Альтернатива без перезапуска — очистить файл: `: > mapsettings.log`.

## Сборка и запуск

- Сборка с отладочной нумерацией: `make build-debug`; после каждой пересборки
  перезапускать фоновый сервер.
- В git коммитить/пушить только по явной команде пользователя.
